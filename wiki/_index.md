# Wiki

The project's knowledge base. Read this page, then the `_index.md` of the folder you need,
before scanning files. Rules: [docs/discipline/literature-wiki.md](../docs/discipline/literature-wiki.md).

Created: 2026-11-05

## Folders

| folder | what it holds |
|---|---|
| [raw/](raw/_index.md) | sources as ingested (papers, notes, catalog pages); never edited |
| [inbox/](inbox/_index.md) | sources someone wants read, not yet ingested; one file each |
| [concepts/](concepts/_index.md) | synthesized articles, one bounded idea each |
| [references/](references/_index.md) | curated collections: reading lists, bibliographies, tables of results |
| [known-results/](known-results/_index.md) | what the literature proves, by object of study |

The activity log is [log.md](log.md): one entry per operation, appended, never edited.
Format: `## [YYYY-MM-DD] operation | description`, for example
`## [2026-03-02] ingest | added the survey on X to raw/ and synthesized concepts/x.md`.
